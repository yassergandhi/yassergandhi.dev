# Reindexación manual V7

1. Desplegar la versión aprobada.
2. Comprobar `/version.json`.
3. Inspeccionar `https://yassergandhi.dev/`.
4. Ejecutar Live Test.
5. Confirmar español, H1, canonical, title, OG y schema.
6. Solicitar indexación una vez.
7. Enviar `sitemap-index.xml`.
8. Revisar canonical elegida.
9. Revisar consultas en inglés.
10. Comparar 16 meses.
11. Documentar fecha y captura.
12. Esperar días o semanas.
13. No solicitar repetidamente.
