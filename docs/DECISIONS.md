# Decisiones

Fecha de corte: 25 de julio de 2026.

## Dirección vigente

North Star V6 gobierna voz, historia, preguntas, focalización, copy público y ritmo de lectura. V5 conserva oferta, precio, evaluación, URLs, métricas, límites comerciales y validación CANACO.

- Categoría: **sitios y sistemas web con investigación cualitativa**.
- Oferta: **Proyecto de sitio o sistema web con investigación cualitativa**.
- Precio: **Desde $24,999 MXN, IVA incluido.**
- Frase narrativa: **Tu negocio no empezó con una página. Empezó con una vida que alguien quería construir.**

La investigación permite comprender qué debe construirse. El diseño y el desarrollo permiten entregarlo. No se venden como servicios separados en la comunicación principal.

## Evaluación y rutas

- Ruta pública y canónica: `https://yassergandhi.dev/evaluacion`.
- Tally: `MeQjR0`; no se cambiaron sus preguntas.

## Medición e infraestructura

Vercel Web Analytics sigue integrado una vez. GA4 permanece suspendido. No se agregaron GTM, Clarity ni píxeles. No se realizaron cambios en DNS, Cloudflare, Vercel, Search Console o Tally.

## Sistema visual

Se conserva la identidad oscura aubergine, naranja Ubuntu, crema, Ubuntu, Ubuntu Mono, menú móvil, disclosures y reduced motion. Se eliminan terminal, proyectos y stacks de la home. Una serif de sistema se usa sólo como acento narrativo. El padding global queda en `clamp(3.25rem, 6vw, 5.5rem)` y `3.25rem` en móvil.

huhuGERMAN pasa al footer como proyecto autoral relacionado, sin stack, tarjeta flotante ni animación. La intro narrativa dura como máximo 1.4 segundos, aparece una vez por sesión, es decorativa y se omite con movimiento reducido.
