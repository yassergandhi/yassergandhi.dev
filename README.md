## The Mission
I build the "invisible infrastructure" of learning. I specialize in the intersection of **Systems Engineering** and **Pedagogical Governance**. 

If you believe that AI should govern pedagogy, we are building the same thing.

## Core Philosophy
- **Pedagogy > Tech:** An AI that doesn't understand the classroom contract is just a hallucination engine.
- **PDR (Pedagogical Decision Record):** My methodology for documenting classroom constraints before a single prompt is fired.
- **No-Fly Zones:** Hard-coding "out-of-scope" pedagogical limits into the LLM.
